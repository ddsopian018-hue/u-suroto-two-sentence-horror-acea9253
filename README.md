A two-sentence horror story about a baby monitor: a new parent watches their daughter breathe on the little kitchen screen for three weeks — until the night the crib is empty, the nursery door is still locked from the inside, and the screen keeps showing her breathing. The second sentence turns the first one inside out: the "breathing" was never the baby. The horror is never named, only implied.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` (exactly two sentences, 350 characters) to `$MAKEFUN_OUTPUT_DIR` (or `/output` when unset).
